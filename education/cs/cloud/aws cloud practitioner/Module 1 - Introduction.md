
AWS is a cloud provider which provides numerous cloud services such as compute and generative AI to businesses. AWS runs a 'pay for what you use' and 'on-demand' model, meaning that a business will only pay for the resources they use.

#### Client-Server Model

**What is it & how does it work?**

The client server model can be thought of as a coffee shop, a client (business) comes and places a request for a coffee (compute from a server), they then pay for it, and the deal is done (the server responds and the client gets their compute).

**Why is it important?**

This is important as it is the bedrock of the AWS model, and acts as the primary resource most businesses use, it also allows full transparency, and businesses only need to pay for what they use.

#### Cloud Computing

**What is it & how does it work?**

Cloud Computing is the on-demand delivery of resources online, with pay-as-you-go pricing, including Storage (AWS S3), Databases, and Networking.

**Why is it important?**

This is important because it changed the way IT services wore used across the world, it allowed for a cost-efficient method of using cloud services without the upfront investment cost.


#### Deployment Models

There are three types of cloud model:

 - On-premises deployment: This is used for businesses that keep proprietary or legacy software, or require low-latency builds.
 - Hybrid deployment: This is a mixture of on-premises and cloud deployment, where some software must me kept offline, but cloud services are required for spikes in use etc.
 - Public cloud deployment: This is the typical model of cloud usage, fully online, and on-demand access.

#### Benefits of the Cloud:

- You can trade fixed expense for variable expense, this can save businesses thousands as they'll only pay for what they use.
- Increase speed and agility, testing environments can be used to test new provisions and methods of using AWS.
- Global use, AWS allows for software to be expanded abroad using deployments to other countries online.

#### Fault Tolerance & High-Availability :

**What is it & how does it work?**

High availability ensures consistent uptime when a component fails, this acts as a failsafe to ensure there is no downtime. Fault tolerance builds on this by designing a system to continue operating when multiple failures occur.

AWS uses regions to ensure consistent uptime, such as in Ohio, Dublin and Paris. Each regions contains sub-regions, so that if one goes down, the the other sub-regions will help balance the load. 

#### Shared Responsibility Model:

AWS runs a shared responsibility model to ensure that user data is kept secure, AWS is responsible for keeping the cloud secure, but the user is responsible is for the data in the cloud.
