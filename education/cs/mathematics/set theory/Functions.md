
**What are functions?**

Functions take an element of set A and turns it into an element of set B. Set A is called the domain, and set B is called the co-domain or range.

```
f: A -> B
(x, f(x))
```
The Cartesian product can be used and visualise the problem as a table.

```
(a1, b1) (a2, b1) (an, b1)
(a1, b2) (a2, b2) (an, b2)
```

f < A x B for every a E A there is one and only one b such (a, b) E f


**Types of Functions:**

- Injection

Example: there are no a1, a2, E A such that a1 /= a2 but f(a1) = f(a2)

- Surjection

Example: for every b E B there is a such that b = f(a)

- Bijection

Example: injection + surjection


Full Example:

f(x) = x²
