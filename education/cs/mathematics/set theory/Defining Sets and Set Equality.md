

Set Theory can be simply a collection of elements. 

Examples:

```
S = {1, 2, 3, 4, 5} # Finite Set
N = {1, 2, 3, ...} # Infinite Set

S2 = {n E N / n2 < 25} # natural numbers belongs to such that n < 25



x E s # x belongs to s


A = B iff for all x x E A iff x E b # A = B if and only if 

# More concise was of the above:

(A=B) <=> ▽ x (x E A) <=> (x E B)
```
1. This is a finite set, meaning it has an ending.
2. The E symbol means 'belongs to'
3. The / symbol means 'such that'
4. The Z symbol means 'integer (numbers)'
5. The Q symbol means 'decimal fractions'
6. The R symbol means 'real numbers'
