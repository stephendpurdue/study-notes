
**What is Scalability?**

Scalability refers to increasing system capacity to increase the amount of load a system can take. 

**How does it work?**

Vertical Scaling: This involves upgrading the components on one machine, eg:
more CPUs, SSDs, RAM etc. A main drawback of this is that a system can only be upgraded so far, or to a certain extent that modern technology will allow.

Horizontal Scaling: This involves increasing the number of machines in the system, rather than upgrading one sole machine. This is typically preferred as it is not as expensive.

**Why is it important?**

Scalability is important for nearly all modern CS practices, especially for large businesses that require systems scaled to thousands of users.
