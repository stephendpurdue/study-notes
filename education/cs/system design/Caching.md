
Caching refers to the saving of information in a cache, typically within the operating system or browser, this can reduce load by lowering the need for constant requests as important information such as a frequently visited IP address is stores locally.

Shared Session State:

A server could be used to hold all this information, and then share it with other servers, allowing a persons state to be kept in memory.

RAID (Redundant Array of Independent Disks):

Allows for data to be split across multiple drives in order to save time.

RAID 1: 

Mirrors data to other drives in the event one goes offline.


Memcached:

Hosts a server that can be used to cache information.
