
#### What happens when a program runs?

When a program is executed, it does three steps:

Fetch -> Decode -> Execute

Instructions are fetched from memory, these are then decoded and executed.

#### What is an Operating System?

An operating system is a large piece of software that acts as the intermediary between hardware and software. This can include using System Calls to interface with programs. The Operating System creates a virtual version of a physical component, such as the processer, mainly for easier use, which is why they are often called Virtual Machines. This is called -> Virtualization.

Operating Systems can be divided into three separate sections.

Virtualisation, Concurrency, and Persistence

#### Virtualisation:

Virtualisation is the act of something being done virtually, in the context of operating systems, this refers to creating an **abstraction layer** which allows virtual copies to be created of a physical resource, this could include a CPU, storage or memory.

#### Concurrency:

Concurrency is the act of completing multiple tasks at the same time 'concurrently'. This can be done by using multiple threads, eg: creating a program with two threads, each tasked to count to 1000, the output would be 2000, as two threads were used, the task was thus completed twice.

#### Persistence:

Persistence relates to storage and ensuring files are stored correctly.
